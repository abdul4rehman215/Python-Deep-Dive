## 🧪 Lab Structure

Each lab follows a **consistent, professional structure**:

```text
labXX-lab-name/
├── README.md             # 📖 Lab explanation, objectives & steps
├── commands.sh           # 💻 Commands executed in terminal
├── output.txt            # 📤 Captured command output
├── *.py                  # 🐍 Python scripts (as required)
├── interview_qna.md      # 🎯 Job-oriented interview Q&A
└── troubleshooting.md   # 🛠️ Common errors & fixes
````

This structure makes the repository:

* ✅ Easy to navigate
* ✅ Interview-friendly
* ✅ Industry aligned
* ✅ GitHub showcase ready

## 🚀 How to Use This Repository

1. **Clone the repository**

   ```bash
   git clone https://github.com/<your-username>/python-deep-dive.git
   ```

2. **Navigate to a lab**

   ```bash
   cd lab21-reading-csv-files
   ```

3. **Read the lab instructions**

   ```bash
   cat README.md
   ```

4. **Run commands**

   ```bash
   bash commands.sh
   ```

5. **Compare output**

   ```bash
   cat output.txt
   ```

6. **Review interview questions**

   ```bash
   cat interview_qna.md
   ```
